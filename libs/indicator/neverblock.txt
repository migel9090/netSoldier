# netSoldier never-block list
#
# Hosts that a threat feed must never turn into an automatic block: blocking
# one would break a household's everyday use of the internet, or every
# unrelated tenant of a shared host, because one feed row said so.
# threat-intel-sync drops a feed indicator that names one of them, and
# libs/indicator exposes the same check (NeverBlock, CheckBlockable) to every
# other service that blocks. A URL indicator on one of these hosts is not
# affected: a URL names one resource, not the host.
#
# Format: "<reason> <scope> <value>", one entry per line.
#   reason  popular | cdn | shared_hosting | dynamic_dns | public_resolver
#   scope   tree  the name and every name under it
#           name  the name itself only; the names under it belong to
#                 customers (tenants) and stay blockable
#           addr  an IP address or prefix; an IP indicator equal to it,
#                 inside it or containing it is refused
#
# Provenance
#
#   popular — selected by hand from the first 600 rows of the
#   Majestic Million of 2026-11-17
#   (https://majestic.com/reports/majestic-million),
#   (c) Majestic-12 Ltd, licensed under CC BY 3.0
#   (https://creativecommons.org/licenses/by/3.0/). Changes made: the rows
#   were reduced to registrable domains with the Public Suffix List, most of
#   them were left out (criteria below), and hosts the same operators run
#   for those sites (content and update hosts, connectivity checks) were
#   added. CC BY permits commercial use and redistribution with attribution.
#   The other rankings in common use were ruled out by their terms:
#   Cloudflare Radar (CC BY-NC 4.0, non-commercial), the Cisco Umbrella
#   popularity list (no licence granted), Tranco (combines both) and Alexa
#   (discontinued, proprietary).
#
#   cdn, shared_hosting, dynamic_dns, public_resolver — first-party, factual
#   entries compiled from the providers' own documentation. Shared hosts and
#   dynamic-DNS zones that the Public Suffix List already lists (github.io,
#   herokuapp.com, duckdns.org, ddns.net, ...) are not repeated: Domain
#   refuses a public suffix as an indicator outright, and their tenants are
#   separate registrable names that stay blockable.
#
# Criteria for "popular": one large operator that runs every name under the
# domain (tree), or whose subdomains are its customers' (name: the apex
# only); a household would notice it blocked; not a link-farm, parking or
# domain-aftermarket name, not a theme or plugin footer artefact, not a
# legacy domain whose ownership could lapse. News, government, universities
# and publishers are left out on purpose: blocking one does not break a
# household, and a compromised one must stay blockable. Every entry is
# immunity from automatic blocking, so the list stays small.
#
# Refresh (yearly, or when a household reports a false block):
#   1. curl -r 0-400000 https://downloads.majestic.com/majestic_million.csv
#      (about the first 5000 rows, header included).
#   2. Reduce the rows to registrable domains
#      (golang.org/x/net/publicsuffix.EffectiveTLDPlusOne) and drop public
#      suffixes and duplicates.
#   3. Review what entered and what left the first 600 against the criteria
#      above; prefer "name" whenever subdomains could belong to customers.
#   4. Update the snapshot date above and NeverBlockSnapshot in
#      neverblock.go, and run the libs/indicator tests: they check every
#      entry's shape and scope against the Public Suffix List.
